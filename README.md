# FiveM Loading Screen Resource

FIVEM_Script_Creator is a FiveM loading screen resource with a custom NUI interface, connection progress display, rotating roleplay tips, team and rules panels, and optional ambient audio controls.

## Install

1. Place the resource folder in your FiveM server's resources directory.
2. Add `ensure FIVEM_Script_Creator` to your server configuration, using the folder's actual name if different.
3. In `web/index.html`, replace the example Discord and social links with your server's links.
4. Adjust the server name, region, tips, team information, and rules in the resource files as needed.
5. Restart the server or start the resource.

## Use

1. Connect to the server. The loading screen appears while the client joins.
2. Follow the displayed progress indicator and rotating tips. The screen closes after the network session starts.
3. Select TEAM or RULES to open the corresponding information panel. Press Escape or select the close button to dismiss it.
4. Use the audio controls to play or pause generated ambient tones, change the tone, and adjust the volume. Audio starts only after you interact with the page.
